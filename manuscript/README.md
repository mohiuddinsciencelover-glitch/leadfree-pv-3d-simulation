# Manuscript assets

This directory holds the figures and the parameter-provenance tables that
accompany the paper.

    figures/       main-text figures, vector PDF at IEEE printed size
    figures_si/    supplementary figures
    MANUSCRIPT_PARAMETER_TABLES.md
                   every parameter, its value, its source and its provenance
                   status ([EXP] / [THEO] / [SIM-LIT] / [DERIVED] / [SWEPT])

The manuscript text itself is not included here pending publication. It will be
added, or replaced by a DOI link to the published article, on acceptance.
